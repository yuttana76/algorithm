## **\*\***\

คำแนะนำสไตล์อาจารย์สำหรับ "วันสัมภาษณ์จริง"
อย่าเพิ่งรีบพิมพ์โค้ด! ให้ใช้กฎ 4 ขั้นตอน (UMPIRE / 4-Step Framework):

- Clarify: ถามเงื่อนไขและ Edge Cases ก่อน (เช่น ลิสต์ว่างได้ไหม? มีเลขติดลบไหม? ค่าซ้ำได้ไหม? ข้อมูลเรียงหรือยัง?)
- Brute Force: พูดแนวคิดตรงไปตรงมาก่อน (เช่น ลูปซ้อน O(n^2)) เพื่อให้ผู้สัมภาษณ์เห็นว่าคุณเข้าใจโจทย์
- Optimize: เสนอวิธีที่ดีกว่าพร้อมบอก Time & Space Complexity แล้วค่อยเริ่มเขียนโค้ดเมื่อผู้สัมภาษณ์พยักหน้าเห็นด้วย
- Dry Run & Test: ไล่โค้ดด้วยมือกับตัวอย่างเล็กๆ และ Edge Cases (เช่น [], มี 1 ตัว, ไม่มีคำตอบ) ก่อนบอกว่าเสร็จ
