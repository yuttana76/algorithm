1. ALGORITHM คืออะไร?
--------------------------------------------------------------------------------
- Algorithm คือ "ลำดับขั้นตอนที่ชัดเจน" เพื่อแก้ปัญหาหนึ่งๆ จาก Input ไปสู่ Output
- ในการสัมภาษณ์ เราไม่ได้ดูแค่ว่า "ทำงานได้ไหม" แต่ดูด้วยว่า:
  1) ใช้เวลาทำงานเร็วแค่ไหน (Time Complexity)
  2) ใช้หน่วยความจำเพิ่มมากแค่ไหน (Space Complexity)


2. หลักการของ LINEAR SEARCH
--------------------------------------------------------------------------------
- แนวคิด: ไล่ตรวจข้อมูลทีละตัวตั้งแต่ตัวแรก (index 0) ไปจนถึงตัวสุดท้าย (index n-1)
- ถ้าเจอค่าที่ตรงกับเป้าหมาย (target) -> หยุดทันทีแล้วคืนตำแหน่ง (index)
- ถ้าตรวจครบทุกตัวแล้วไม่เจอ -> คืนค่า -1 (ธรรมเนียมสากลแปลว่า "หาไม่เจอ")
- เปรียบเทียบชีวิตจริง: เหมือนการเปิดดูไพ่ที่วางคว่ำแบบไม่ได้เรียงเลขทีละใบจนกว่าจะเจอใบที่ต้องการ


3. ตัวอย่างโค้ด PYTHON (อ้างอิงคู่กับ linearSearch.py)
--------------------------------------------------------------------------------
def linear_search(nums: list[int], target: int) -> int:
    for i in range(len(nums)):       # (1)
        if nums[i] == target:        # (2)
            return i                 # (3)
    return -1                        # (4)

# ทดลองเรียกใช้งาน
numbers = [10, 25, 7, 42, 15]
result = linear_search(numbers, 42)
print("เจอที่ตำแหน่ง (index):", result)  # Output: 3


4. อธิบายโค้ดทีละบรรทัด (LINE BY LINE)
--------------------------------------------------------------------------------
def linear_search(nums: list[int], target: int) -> int:
  - ประกาศฟังก์ชันรับ Input 2 ตัว:
    * nums   : ลิสต์ของตัวเลขที่จะเข้าไปค้นหา
    * target : ค่าเป้าหมายที่ต้องการหา
  - คืนค่ากลับเป็น int (ตำแหน่ง index ที่พบ หรือ -1 หากไม่พบ)

(1) for i in range(len(nums)):
  - len(nums) คือจำนวนสมาชิกทั้งหมดในลิสต์ (ตัวอย่างนี้คือ 5)
  - range(5) สร้างเลข index ตั้งแต่ 0, 1, 2, 3, 4 เพื่อวนลูปตรวจทีละช่อง

(2) if nums[i] == target:
  - ดึงค่าในช่องที่ i มาเปรียบเทียบกับ target ว่าเท่ากันหรือไม่

(3) return i
  - ถ้าเท่ากัน ให้หยุดฟังก์ชันทันทีและส่งตำแหน่ง i กลับออกไป (ไม่เสียเวลาตรวจตัวที่เหลือ)

(4) return -1
  - อยู่ "นอกลูป for" จะทำงานก็ต่อเมื่อวนครบทุกตัวแล้วไม่เจอ target เลย


5. การไล่การทำงานทีละก้าว (DRY RUN)
--------------------------------------------------------------------------------
ตัวอย่าง Input: nums = [10, 25, 7, 42, 15], target = 42

  รอบที่ |  i  | nums[i] | nums[i] == 42? | สิ่งที่ทำ
  -------|-----|---------|----------------|---------------------------
    1    |  0  |   10    |     ไม่ใช่     | วนรอบถัดไป
    2    |  1  |   25    |     ไม่ใช่     | วนรอบถัดไป
    3    |  2  |    7    |     ไม่ใช่     | วนรอบถัดไป
    4    |  3  |   42    |     ใช่!       | return 3 (จบการทำงานทันที)


6. การวิเคราะห์ BIG-O (TIME & SPACE COMPLEXITY)
--------------------------------------------------------------------------------
[Time Complexity - เวลาทำงาน]
  * Best Case  (กรณีดีที่สุด)  : O(1) -> เจอตั้งแต่ตัวแรก (index 0)
  * Worst Case (กรณีแย่ที่สุด)  : O(n) -> อยู่ตัวสุดท้าย หรือไม่มีในลิสต์เลย (ตรวจครบ n ตัว)
  * Average Case (กรณีเฉลี่ย)  : O(n) -> โดยเฉลี่ยตรวจประมาณ n/2 ตัว (ตัดค่าคงที่เหลือ O(n))
  ** หมายเหตุ: ในการสัมภาษณ์ มักอ้างอิง Worst Case เสมอ ดังนั้น Linear Search = O(n) **

[Space Complexity - หน่วยความจำที่ใช้เพิ่ม]
  * O(1) (Constant Space)
  * เพราะไม่ได้สร้างลิสต์หรือโครงสร้างข้อมูลใหม่เพิ่มตามขนาด Input ใช้แค่ตัวแปร i ตัวเดียว


7. จุดเด่น ข้อจำกัด และการใช้งานจริง
--------------------------------------------------------------------------------
[จุดเด่น]
  + เข้าใจง่าย เขียนโค้ดสั้น ไม่ซับซ้อน
  + ไม่จำเป็นต้องเรียงลำดับข้อมูล (Unsorted Data) ก่อนค้นหา
  + ประหยัดหน่วยความจำ O(1)

[ข้อจำกัด]
  - ช้าเมื่อข้อมูลมีขนาดใหญ่มาก (เช่น ข้อมูล 10 ล้านตัว อาจต้องวนสูงสุด 10 ล้านรอบ)

[ตัวอย่างการใช้งานจริง]
  - ค้นหาข้อมูลในลิสต์ขนาดเล็ก (เช่น รายการสินค้าในตะกร้า 10-50 ชิ้น)
  - ข้อมูลที่ไม่ได้เรียงลำดับ และต้องการค้นหาเพียงครั้งเดียว (ไม่คุ้มค่าเสียเวลา Sort ก่อน)
  - เบื้องหลังคำสั่งมาตรฐานของ Python เช่น:
      * x in my_list         -> ทำงานแบบ Linear Search: O(n)
      * my_list.index(x)     -> ทำงานแบบ Linear Search: O(n)
      * my_list.count(x)     -> ทำงานแบบ Linear Search: O(n)


8. EDGE CASES ที่ควรถามและเช็กในวันสัมภาษณ์
--------------------------------------------------------------------------------
  1) ลิสต์ว่าง: nums = [], target = 5
     -> ไม่เข้าลูป for เลย คืนค่า -1 ทันที (โค้ดนี้รองรับแล้ว)
  2) ไม่มีค่าที่ต้องการ: nums = [10, 25, 7], target = 99
     -> ตรวจครบทุกตัว คืนค่า -1
  3) มีค่าซ้ำหลายตำแหน่ง: nums = [10, 42, 7, 42], target = 42
     -> โค้ดนี้คืนตำแหน่ง "แรก" ที่เจอ (index 1)
     -> ควรถามผู้สัมภาษณ์ว่าต้องการ index แรก, index สุดท้าย, หรือทุก index ที่เจอ?
  4) มีสมาชิกแค่ 1 ตัว: nums = [42], target = 42 -> คืน 0 / target = 5 -> คืน -1

        def linear_search_all(nums: list[int], target: int) -> list[int]:
            result = []
            for i in range(len(nums)):
                if nums[i] == target:
                    result.append(i)
            return result
